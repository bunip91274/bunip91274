## 🚀 Projects

### 📊 [Personal Finance Tracker](https://github.com/bunip91274/Personal-Finance-Tracker)
A desktop expense tracker built with **Tkinter** that logs transactions to CSV and visualizes spending by category with **Matplotlib** pie charts. Supports importing existing CSV files (including Excel's UTF-8-with-BOM exports), input validation, and one-click data reset.

`Python` `Tkinter` `Matplotlib` `CSV`

### 🃏 [Blackjack](https://github.com/bunip91274/Blackjack)
A complete text-based Blackjack game with betting, double-down, dealer AI that hits to 17, dynamic Ace scoring, and a file-loaded multi-deck shoe that reshuffles when it runs low.

`Python` `Game Logic` `File I/O`

### 🧮 [Calculator](https://github.com/bunip91274/Calculator)
A GUI calculator built with Tkinter supporting the four basic operations, with error handling for invalid input.

`Python` `Tkinter`

### 🔐 [Password Generator](https://github.com/bunip91274/Password-Generator)
A CLI tool that generates strong passwords (mixed case, digits and symbols at a user-chosen length) or memorable word-based ones.

`Python` `CLI`

### 🚌 HSR Bus Tracker *(in progress)*
A trip planner for McMaster students: pick your residence and a destination anywhere in Hamilton, and it tells you which stop to walk to, which bus to take, its ETA, and when to leave.

`Python` `Transit Data` `In Development`
